# Спецификация MVP — чат-бот мастерской «Глина»

## 1. Легенда проекта

**Мастерская керамики, декора и авторской мебели «Глина»** — небольшой
консультационный сервис с понятным каталогом услуг. Всё изготавливается вручную
на заказ.

## 2. Для кого бот и какую задачу решает

Для посетителя сайта мастерской, которому нужно быстро:

- открыть чат и увидеть главное меню;
- посмотреть услуги и цены «от …»;
- прочитать FAQ;
- оставить обычную заявку через сценарный bot-flow;
- задать вопрос ИИ-консультанту по материалам компании;
- получить помощь с выбором услуги и черновиком заявки.

Бот снижает рутину мастерской: типовые вопросы закрываются каталогом и FAQ, а
ИИ-консультант отвечает только по базе знаний и готовит черновик заявки, который
сохраняется только после подтверждения пользователя.

## 3. Услуги (5)

1. Керамическая посуда на заказ — от 1 500 ₽
2. Декор и предметы интерьера — от 3 000 ₽
3. Подарочные наборы и сервизы — от 8 000 ₽
4. Мастер-класс по лепке и гончарному кругу — от 2 500 ₽
5. Авторская мебель и крупные изделия — от 25 000 ₽

## 4. FAQ (4 категории)

- Услуги
- Стоимость
- Сроки и формат работы
- Правила и контакты

## 5. Данные для заявки

- услуга, которая интересует;
- краткое описание задачи;
- контакт для связи (имя + телефон, email или Telegram).

## 6. Данные, которые бот НЕ должен запрашивать

- платёжные данные (номер карты, CVV, пароли платёжных сервисов);
- пароли и коды подтверждения;
- паспортные и другие избыточные персональные данные;
- данные о здоровье, доходах и другая чувствительная информация.

## 7. Обычный bot-flow и ИИ-консультант — разница

| | Обычный bot-flow | ИИ-консультант |
|---|---|---|
| Источник ответов | Зашитый сценарий (меню, услуги, FAQ) | knowledge/ + AI Studio API |
| Обращение к модели | Нет | Да |
| Работа без API-ключа | Да | Нет (честно сообщает о недоступности) |
| Заявка | Пошаговый сбор (услуга → задача → контакт) | Черновик через prepare_lead_draft + подтверждение |
| source в leads | `bot_flow` | `ai_consultant` |

## 8. Ограничения ИИ-консультанта

- отвечает только по knowledge/ (`services.md`, `faq.md`, `rules.md`);
- не выдумывает цены, сроки, скидки и гарантии, которых нет в базе знаний;
- не читает `.env`, скрытые файлы, абсолютные пути и файлы вне `knowledge/`;
- не выполняет shell-команды и не работает с произвольной файловой системой;
- задаёт 1–2 коротких уточняющих вопроса;
- готовит черновик заявки, но не сохраняет её сам — только после подтверждения;
- если информации нет — честно говорит об этом и предлагает оставить заявку.

## 9. План реализации по слоям

- **interface** — `static/` (HTML/CSS/JS): чат с историей, меню, поле ввода, быстрые кнопки, карточка черновика.
- **backend** — `app.py` (FastAPI, один runtime), `bot_flow.py` (сценарный поток), `ai_client.py` (AI Studio API), `agent_runtime.py` (agent loop).
- **database** — `storage.py` (SQLite `data/bot.sqlite3`): таблицы `leads` и `feedback`.
- **agent** — `agent/tools.py` (search_knowledge, read_knowledge_file, prepare_lead_draft, save_confirmed_lead), `agent/soul.md` (роль и ограничения), `knowledge/` (база знаний).

## 10. Граница MVP

**Входит:** локальный запуск, один runtime, web-интерфейс чата, сценарный
bot-flow, ИИ-консультант по базе знаний, SQLite, README, запуск на VPS.

**Не входит:** домен, публичная ссылка, отдельный кабинет управления, внешний
production-контур, оплата, CRM, автодеплой и аналитика.
